薙刀式キーボード 設定ツール PCカスタマイズ (#12 フェーズ2)

USB接続した薙刀式キーボードの配列（単打・シフト面・コンボ・編集モード）と パラメータを、再ビルド／UF2書込みなしに編集します。Chrome / Edge（WebHID対応）専用。 変更は COMMIT で端末フラッシュへ保存し、再起動後に反映されます。

未接続
このブラウザは WebHID 非対応です。Chrome / Edge（デスクトップ版）で開いてください。

物理配置の上で編集。薙刀式キーは単打面のかな/キーを直接編集。未使用の物理キーは「学習」で位置を取り込み、直接キー（F1-12/Del/PageUp/矢印/Win等）やマクロを割当。

未使用キーの直接割当

面ごとに sc→かな（または特殊キー）を編集。かなは直接入力、キー操作は記号を追加。

2キー／3キー同時押しコンボのかな。既存の置換＋空欄行で新規追加も可。

3キーコンボ

編集モード1/2の各キーのキー操作（カーソル/コピペ等）を記号列で編集。

保存 / 反映

「端末へ送る」はRAMステージングのみ。COMMITでフラッシュ保存し、再起動で反映。

VID/PID 0xc0de:0xcafe / vendor HID usagePage 0xFF00 / proto v2。設定は USBに挿した（マスタ）半身 のフラッシュに保存されます。フェーズ2ファーム初回書込みで旧(v1)設定は一度リセットされます。
