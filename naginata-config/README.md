# 薙刀式キーボード 設定ツール

USB接続した薙刀式 分割キーボードの**配列（単打・シフト面・コンボ・編集モード）**と
**パラメータ**を、再ビルド／UF2書込みなしにブラウザから編集する設定ツールです。
VIA ライクな UI（物理キーボード描画＋クリック選択＋下部パレット＋即時反映）を採用しています。

## 使い方

1. Chrome / Edge（デスクトップ版、WebHID対応）で `index.html` を開く
2. 「端末に接続」→ デバイス選択ダイアログで薙刀式キーボードを選ぶ
   （一度許可すれば次回からは自動再接続）
3. キーをクリック → 下部パレットから かな / キー操作 を割当（即座に端末RAMへ送信）
4. **保存 (COMMIT)** でフラッシュへ書き込み → **再起動** で反映

実機がなくても、ウェルカム画面の「デモデータで試す」または `index.html#demo` で
サンプル配列を使ってUIを試せます。

## 画面

| ペイン      | 機能                                                                                                                                                              |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| キーマップ  | レイヤー（単打・各シフト面・編集モード1/2）ごとのキー割当編集。未使用物理キー（破線）のクリック割当※・QWERTY/カスタムレイヤー（最大8、未割当キーは QWERTY 透過）※ |
| コンボ      | キーボード上で2〜3キーを選んで同時押しコンボを編集・新規作成                                                                                                      |
| 直接キー    | 薙刀式で未使用の物理キーへ F1-12 / 矢印 / Win 等を割当（キー学習）。ホールド（押しっぱなし保持）※・レイヤー活性化キー MO(n)/TG(n)※                                |
| パラメータ  | 同時打鍵窓・デバウンス・リピート・LED輝度・パススルー時の IME 自動切替※                                                                                           |
| 保存 / 読込 | COMMIT / 再起動 / RESET、設定のJSON書き出し・読み込み                                                                                                             |

※ は対応ファームウェア（fw 0.3+。INFO の capability ビットで自動検出）でのみ表示。
旧ファームウェアでは従来機能のみの表示に自動で切り替わります。
キーボード描画は実機の形状データ（READ_LAYOUT、YAML に記載がある場合）があれば
スタッガー・親指キー込みの実機通り、なければ動的グリッドになります。

## 動作要件・対象デバイス

- Chrome / Edge デスクトップ版（WebHID必須。Firefox / Safari 不可）
- VID/PID `0xc0de:0xcafe`、vendor HID usagePage `0xFF00`、プロトコル v2（フェーズ2ファームウェア）
- 設定は USB に挿した（マスタ）半身のフラッシュに保存されます

## 開発時の注意

`app.js` 内の `CMD`/`SEC`・`SYMBOLS`・`SC_LABEL`・`SHIFT_BITS` はファームウェア側
（`firmware/src/usb_config.rs`・`build.rs`・`layout/naginata.yaml`）のミラーです。
ファーム変更時は手動で同期してください（詳細は [docs/README.md](docs/README.md) の対応表）。
