# 03. UI仕様（VIAライクUX）

## 1. 画面構成

```
┌────────────────────────────────────────────────────────────┐
│ トップバー: ロゴ│接続/デモ│デバイス名│⟳│状態│●未保存│COMMIT│再起動 │
├─────────┬──────────────────────────────────────────────────┤
│サイドバー │ ペイン（キーマップ / コンボ / 直接キー / パラメータ / 保存・読込）│
│         │                                                  │
│ ⌨ キーマップ│   [レイヤーバー]                                   │
│ ⧉ コンボ   │   [物理キーボード描画]                              │
│ ＋ 直接キー │   [エディタドック（下部パレット, sticky）]            │
│ ⚙ パラメータ│                                                  │
│ ⇅ 保存/読込│                                                  │
└─────────┴──────────────────────────────────────────────────┘
```

未接続時はウェルカム画面（接続／デモ起動ボタン）。WebHID 非対応ブラウザでは警告を表示し接続不可。

## 2. キーボード描画（`renderKeyboard`）

- `physMap`（READ_MATRIX_FULL の結果。旧FWでは READ_MATRIX から合成）から左右半身を描画。
  **行・列の範囲は physMap に現れる集合から動的に決定**（左手=昇順、右手=降順ミラー）。
- `layoutMap`（READ_LAYOUT。capability LAYOUT 時）があれば**絶対座標配置**:
  1u=64px（0.25u=16px）でキーを `position:absolute` 配置し、`rot` は CSS rotate。
  形状未記載のキーは最下段へグリッド配置でフォールバック。layoutMap が空ならグリッド描画。
- physMap に無い位置は淡い破線の空セル（クリック不可）。
- `sc=0` の**未使用物理キー**は破線キーとして表示（左上ラベルは `r{row}c{col}`、
  刻印は EXTRA 割当値）。キーマップペインではクリックで EXTRA 割当ドックへ。
  コンボペインではクリック不可（`inert`）。
- カスタムレイヤー表示中、未割当キーは「▽」（QWERTY へ透過）の `trns` スタイル。
- キーキャップの表示:

| 要素 | 内容 |
|---|---|
| 左上（小） | QWERTY 物理ラベル（`SC_LABEL`） |
| 中央（大） | 現在の割当値。かな=そのまま、キー操作=記号名の連結（`symName`）。空は `·` |
| 右上ドット | 青=既定から変更済（overridden）、橙=送信待ち（dirty） |
| 緑枠＋緑背景 | 選択中 |

- 値変更時は `refreshAfterEdit()` が `data-rowref` 経由で刻印・ドットだけを更新（再描画なし）。

## 3. キーマップペイン

- **レイヤーバー**: `model.layers` に存在する mask（昇順）＋ `model.modes` に存在する mode を
  ピル型ボタンで列挙。例: 単打 / センター / 右濁(J) / 左濁(F) / 右半(M) / 左半(V) / 小(Q) / 編集モード1 / 編集モード2。
  capability CUSTOM_LAYERS があれば続けて**カスタムレイヤー**（エントリのあるレイヤー ∪
  セッション中に追加したレイヤー。layer 0 は「QWERTY」、1.. は「カスタムn」）と
  「＋ レイヤー追加」ボタン（上限 `info.maxCustomLayers`）。
- キーをクリック → その (layer, sc) の行を選択しドックで編集。行が無い位置は空行を遅延生成
  （空のままなら送信されない）。
- かなタブの可否: シフト面（mask）= かな＋キー操作、編集モード = キー操作のみ初期タブ、
  カスタムレイヤー = キー操作のみ（かな不可。ホールド・レイヤー操作可）。
- カスタムレイヤー表示中はペイン下部に透過（▽）とレイヤー有効化方法の注記を表示。

## 4. エディタドック（VIAの下部キーコードパレット相当）

ペイン下部に sticky 配置。未選択時は「キーを選択してください」。

```
┌──────────────┬──────────────────────────────────────┐
│ 選択キー・面    │ [かな] [キー操作]  ← タブ               │
│ 現在値（大）    │                                      │
│ 既定: …       │  （タブごとのパレット）                   │
│ [既定に戻す]   │                                      │
│ [クリア/削除]  │                                      │
└──────────────┴──────────────────────────────────────┘
```

### 4.1 かなタブ

- テキスト入力欄（IME直接入力可）＋ ⌫（1文字削除）＋ 最大バイト数表示（`info.maxKanaLen`）。
- 五十音パレット: 清音 / 濁音・半濁音 / 小書き・記号 の 3 グループ。
- **パレットクリックは入力欄への追記**（置換ではない）。拗音など複数文字値に対応するため。
- 入力のたびに `{tag:0, kana}` へ変換し、350ms デバウンスで自動送信。

### 4.2 キー操作タブ

- 「割当列」: 現在のストローク列をチップ表示（× で個別削除）。
- 修飾トグル: Ctrl / Shift / Alt / GUI（複数 ON 可）。パレットクリック時に OR される。
- キーパレット: 編集・移動（プリセット記号）/ ファンクション・特殊 / 文字（A–Z, 0–9）/ 修飾キー単体。
- クリックで `(usage, base_mod | トグル中の修飾)` を 1 ストロークとして末尾に追加。
- **タブを開いただけでは値を変換しない**（キー追加時に初めて TAG_KEYS 化）。閲覧のみで
  dirty になる事故の防止（実装時に修正したバグ。レビュー観点）。
- **動作切替（EXTRA/カスタム ＋ capability HOLD）**: 「動作: タップ列 / ホールド」トグルを表示。
  ホールドでは保持キー 1 つだけを選択でき、値は `{tag:2, hold:[u,m]}`。
  刻印・チップは `名前⤓` で表示。
- **レイヤー操作グループ（EXTRA/カスタム ＋ capability PASSTHROUGH）**: MO(n)/TG(n) を列挙
  （layer 0 は「QWERTY(押下中)/(切替)」、1.. は「カスタムn(押下中)/(切替)」。
  CUSTOM_LAYERS 非対応 FW では layer 0 のみ）。クリックすると値全体を擬似 usage の
  単独ペアで**置換**する（追記ではない）。

### 4.3 左側の操作

| ボタン | 挙動 |
|---|---|
| 既定に戻す | `cur = def` にして即送信（端末上はオーバーライド削除） |
| クリア | 現タグの空値に。def 無し行ならオーバーライド削除として送信 |
| 削除（deletable な行のみ） | クリア＋未送信なら model から行ごと除去 |

## 5. コンボペイン

- キーボード上でキーをクリックしてコード（2〜3キー）を選択。選択は昇順 sc に正規化。
  - 3 キー選択済みで別キーをクリック → 選択をそのキー 1 つにリセット。
- コードが既存コンボに一致 → そのコンボをドックで編集。
- 一致なし＆2〜3 キー選択中 → 「このコンボを作成」ボタン（def 無し・空かなの新規行）。
- 下部に 2キー / 3キーコンボの一覧（keycap風チップ → 値）。クリックで選択。
  既定なし・空・未編集の行は一覧に出さない（作成中の行は選択中のみ表示）。
- キーボードの刻印は単打面（mask 0）のかなを参考表示。

## 6. 直接キーペイン（EXTRA）

- 推奨フロー（capability MATRIX_FULL）: **キーマップ画面の破線キーを直接クリック**して割当。
- フォールバック: 「＋ キーを学習」→ 端末上で未使用物理キーを押す → 位置 `[hand,row,col]` を
  取得し行を追加、即ドックで編集（キー操作タブのみ。かな不可）。学習で見つけた位置が
  physMap に無ければ描画にも追加する。
- 一覧は「右 r2 c5」形式のラベル → 値。削除可（deletable）。破線キークリックで生成された
  だけの空行は一覧に出さない。
- 学習は実機接続時のみ（デモでは学習不可の旨を表示）。

## 7. パラメータペイン

- 5 項目（02-protocol.md §3）をスライダー＋数値入力で編集。範囲クランプあり。
- 変更は 400ms デバウンスで `WRITE_PARAMS`（全項目一括）。
- capability PASSTHROUGH があれば「パススルーモード（QWERTY）」カードを追加表示:
  「IME を自動切替する」チェックボックス（params flags bit0）。

## 8. 保存 / 読込ペイン

- **端末への保存**: COMMIT / 再起動ボタン（トップバーと同機能）。
- **設定ファイル (JSON)**: 書き出し / 読み込み。
- **初期化**: RESET（確認ダイアログ → 全オーバーライド消去 → 再読込）。

### 設定ファイル形式

```json
{
  "app": "naginata-config",
  "version": 2,
  "params": { "window_ms": 60, "tap_ms": 10, ... },
  "layers":  [ { "key": [mask, sc],      "value": { "kana": "あ" } }, ... ],
  "combo2":  [ { "key": [sc, sc],        "value": { "kana": "ん" } }, ... ],
  "combo3":  [ { "key": [sc, sc, sc],    "value": ... } ],
  "modes":   [ { "key": [mode, sc],      "value": { "keys": [[usage, mod], ...] } } ],
  "extra":   [ { "key": [hand, row, col],"value": { "keys": ... } } ],
  "custom":  [ { "key": [layer, sc],     "value": { "keys": ... } } ]
}
```

- 書き出すのは **overridden な行のみ**（既定からの差分）＋パラメータ（flags 含む）。
- 読み込み時: `app` フィールド検証 → params をクランプ適用 → 各エントリを key で照合
  （無ければ行を新規作成）→ `flushAllStaged()` で全変更を端末へ送信（COMMIT は手動）。
- 値は `kana` / `keys` / `hold`（`[usage, mod]`）のいずれかを持つオブジェクト。
  どれも欠ける・型不正のエントリはスキップ。

## 9. 接続まわり

- **自動再接続**: ページロード時に `navigator.hid.getDevices()` で許可済みデバイス
  （vendorId 0xc0de かつ usagePage 0xff00 のコレクションを持つ）を探し、あれば無断で接続。
- **切断検知**: `hid.disconnect` イベントでウェルカム画面に戻す。
- **離脱警告**: `beforeunload` で uncommitted（フラッシュ未保存）ならブラウザ標準の確認を出す
  （デモモードは除く）。
- **デモモード**: 「デモ」ボタンまたは URL `#demo`。実機なしでサンプル配列を読み込み。
  WRITE は模擬（model 更新のみ）。RESET / 再起動 / キー学習は無効。
  サンプル配列は実機の既定（codegen由来）とは**異なる**。

## 10. ステータス表示

- トップバー中央にステータステキスト。`ok`（緑）は 4 秒で自動消去、`err`（橙）は残留。
- WRITE 成功時は「端末へ送信しました（未保存）」、COMMIT 成功時は「フラッシュへ保存しました。再起動で反映されます。」
