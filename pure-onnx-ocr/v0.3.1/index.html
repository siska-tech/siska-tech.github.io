PaddleOCR PP-OCRv6 / PP-OCRv5 モデルをブラウザだけで実行（画像はサーバーへ送信されません）

v0.3.1 v0.2.0 v0.1.0 GitHub

モデル

PP-OCRv6 は Hugging Face（PaddlePaddle 公式）から初回のみダウンロードし、ブラウザにキャッシュします。

マルチスレッドには cross-origin isolation が必要です。

大きくすると小さな文字を拾いやすくなりますが、処理が遅くなります。
