# 薙刀式タイピング練習 (naginata-trainer)

[薙刀式 v15fix](https://oookaaa.wixsite.com/naginata) かな配列の練習用Webアプリです。
[DividedKanaKeyboard](https://github.com/siska-tech/DividedKanaKeyboard)(薙刀式をファームウェアで実装した分割キーボード)の**実機ローマ字送出**に対応しています。

## 起動方法

ビルド不要の静的Webアプリです。`index.html` をブラウザで開くだけで動きます。

```
start index.html
```

ローカルサーバを使う場合:

```
python -m http.server 8000
# → http://localhost:8000
```

## 実機(DividedKanaKeyboard)対応について

DividedKanaKeyboard は、かなを**訓令式ベースのローマ字**として USB HID で送出します
(ファームウェアの `naginata-core/src/romaji.rs` 準拠)。本アプリはその表記を第一候補として判定します:

| かな                             | 実機送出                         | 備考                          |
| -------------------------------- | -------------------------------- | ----------------------------- |
| し / ち / つ / ふ / じ / ぢ / づ | si / ti / tu / hu / zi / di / du | 訓令式                        |
| ん                               | nn                               | 常に nn                       |
| 促音(かっこ)                     | kakko                            | 次の子音を重ねる(単独は xtu)  |
| 拗音(きゃ/しゃ)                  | kya / sya                        | 子音 + ya/yu/yo               |
| 外来音(ふぁ/てぃ)                | huxa / texi                      | 基本かな + 小書きの連結       |
| ー / 、 / 。                     | - / , / .                        | 。、の後の Enter は無視される |

ヘボン式(shi・cha・fa・thi など)や `n+子音`、`xtu/ltu` といった一般的な代替表記でも判定が通るため、
実機がなくても通常のキーボードでのローマ字手打ちで配列の運指を覚える練習ができます。

> **重要**: 練習時は IME をオフ(半角英数)にしてください。実機では `f+g` で IME OFF です。
> IME がオンのまま入力するとアプリが警告を表示します。

## 薙刀式エミュレーションモード

実機がなくても、**通常のQWERTYキーボードで薙刀式の同時押しをそのまま練習**できるモードです。
メニューの「入力モード」で切り替えます(設定は保存されます)。

- ファームウェアの同時打鍵判定(大岡式遅延確定)を簡易再現:
  単打 / センターシフト(スペースを押しながら)/ 濁音(f・j)/ 半濁音(v・m)/
  小書き(q)/ 清音拗音の2キー同時 / 濁音拗音・外来音の3キー同時
- シフトキーはタップで単打かな(f=か など)、押しながらでシフトとして機能
- `f+g` / `j+h` / `v+m`(実機ではIME切替・Enter)はかなを出さない
- **同時押し判定窓**は 30〜120ms で調整可能(実機は40ms。最初は大きめがおすすめ)
- 物理キー位置(`KeyboardEvent.code`)で判定するため、OSのキー配列設定に依存しません
- ヒント行には次のかなに必要なキーの組み合わせを表示します

## 機能

- **レッスン10種**: 中段単打 → 上段 → 下段 → センターシフト → 濁音 → 半濁音 → 拗音 → 外来音 → 総合(単語/文章)の段階式
- **キーボードガイド**: 次のかなに必要な同時押しキーを薙刀式の分割キーボード図上にハイライト
  (センターシフト/濁音シフト f・j/半濁音シフト v・m/小書きシフト q は色付きで区別)
- **ローマ字ヒント**: お題全体の実機送出表記を常時表示(入力済み部分は緑)。
  拗音は `sya` 形式で表示されるが、`sha` や `sixya`(し+小書きゃ分割形)などの代替表記でも判定が通る
- **統計**: かな/分・正確率・ミス数・経過時間、レッスンごとの自己ベストを localStorage に保存
- **カスタム練習**: 任意のひらがなテキスト(1行1問)で練習可能

### ゲーミフィケーション

- **コンボ**: ミスなく打ち続けるとコンボが伸び、スコア倍率が上がる(10コンボごとに +25%、最大 ×2)。
  打鍵音もコンボに応じて音程が上がり、25コンボごとに演出が入る
- **スコアとランク**: レッスン終了時に かな/分 × 正確率² で S/A/B/C/D のランクと ★ を判定。
  レッスンカードに自己ベスト(スコア・ランク・★)を表示
- **XP・レベル**: スコアとランクに応じて XP を獲得し、レベルが上がる(メニュー上部にレベルバー表示)
- **効果音**: Web Audio で合成(外部ファイル不要)。打鍵音・ミス音・お題クリア・コンボ・ランク別ファンファーレ・
  レベルアップ。右上の 🔊 ボタンでオン/オフ(設定は保存される)
- **PERFECT演出**: お題をノーミスでクリアすると金色の火花と「PERFECT!」+ボーナス点。
  レッスン全体をノーミスで終えると「ALL PERFECT!」の紙吹雪と特別ファンファーレ(Sランクでも紙吹雪)

### お題ファイルの追加

メニューの「お題ファイルの追加」に `.txt` / `.json` をドラッグ&ドロップ(またはファイル選択)すると
レッスンとして追加され、localStorage に保存されます(削除は各カードの × ボタン)。
サンプルは `samples/` にあります。

`.txt` 形式(1行1問。`#` で始まる行はコメント、最初の1つがタイトル):

```
# ことわざ
さるもきからおちる
ねこにこばん
```

`.json` 形式(単一オブジェクトまたは配列で複数レッスン):

```json
[
  { "title": "たべもの", "desc": "せつめい(省略可)", "items": ["おにぎり", "らーめん"] }
]
```

かなとして解釈できない行(漢字・英数のみ等)は読み込み時に除外されます。

## ファイル構成

```
index.html        エントリポイント
css/style.css     スタイル
js/data.js        薙刀式 v15fix 配列定義・ローマ字テーブル・レッスン
js/romaji.js      モーラ分割 + ローマ字前方一致マッチャ
js/emulator.js    薙刀式エミュレーション(同時打鍵判定エンジン + かなマッチャ)
js/lessonio.js    お題ファイル(.txt/.json)パーサ
js/sound.js       効果音(Web Audio 合成)
js/fx.js          画面エフェクト(パーティクル)
js/keyboard.js    キーボードガイド描画
js/app.js         画面遷移・入力処理・統計・ゲーミフィケーション
samples/          お題ファイルのサンプル
docs/             設計資料(実装仕様・設計判断・検証記録)
test/run-tests.js テスト(node test/run-tests.js)
test/browser-probe.html ブラウザ実行パスの検証ページ
```

設計の詳細は [docs/](docs/README.md) を参照。

## テスト

```
node test/run-tests.js
```

全レッスン項目のトークン化・実機ローマ字での完走・`romaji.rs` のテストケースと同一の固定値・
ヘボン式代替表記の受理・ミス判定・キーガイドの対応を検証します。

## 配列データの出典

`js/data.js` の配列定義は DividedKanaKeyboard の
`naginata-core/layout/naginata.yaml`(薙刀式 v15fix)および `naginata-core/src/romaji.rs` を転記したものです。
編集モード(D+F / C+V)は文字入力ではないため練習対象外です。
