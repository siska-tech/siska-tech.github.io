## データ構造

### KEYBOARD(表示専用)

キーボードガイド描画用。`left`/`right` × 3段 × 5キーの配列。
各キー: `{ id: QWERTYキー, main: 単打かな, sub: センターシフトかな, shift?: 'small'|'daku'|'handaku', fn?: true }`
`fn` は t(←)・y(→)・u(⌫)などかなを持たないキー。スペースは描画側でハードコード。

### KANA_KEYS(かな→押下キー)― 最重要テーブル

```
'か': ['f']           単打
'さ': ['SP', 'u']     センターシフト('SP' = スペース)
'ざ': ['f', 'u']      濁音(逆手親指シフト)
'ぱ': ['m', 'c']      半濁音(逆手中指シフト)
'ゃ': ['q', 'h']      小書き(qシフト)
'きゃ': ['w', 'h']    清音拗音 combo2(非シフト2キー)
'ぎゃ': ['j', 'w', 'h'] 濁音拗音 combo3
'ふぁ': ['v', ';', 'j'] 外来音 combo3
```

**規約**: 2キー定義は「シフトキーが先頭」。これを前提に emulator.js が
逆引きテーブル(単打面/レイヤ面/combo2/combo3)を自動構築する(04章)。
このテーブルが配列定義の単一情報源であり、キーボードガイドのハイライトと
エミュレーションの両方がここから導出される。

シフト能力キー(naginata.yaml の shifts 節):

| キー | 名称 | 役割 |
|------|------|------|
| Space | CENTER | センターシフト |
| j | R_THUMB | 右親=左手かなの濁音 |
| f | L_THUMB | 左親=右手かなの濁音 |
| m | R_MID | 右中=左手かなの半濁音 |
| v | L_MID | 左中=右手かなの半濁音 |
| q | A_KEY | 小書きシフト |

### ROMAJI(かな→ローマ字候補)

`'し': ['si', 'shi', 'ci']` のように配列で持つ。
**先頭要素は必ず実機ファームウェアが送出する表記**(romaji.rs の訓令式)。
以降はヘボン式などの手打ち用代替。ヒント表示・実機表記の算出は常に `alts[0]` を使う。

romaji.rs の重要仕様(そのまま踏襲):

- 訓令式: si / ti / tu / hu / zi / di / du
- ん → 常に `nn`
- 促音っ → 次モーラの頭子音を重ねる(単独・母音前は `xtu`)
- 拗音(い段+ゃゅょ)→ 子音+ya/yu/yo(きゃ=kya、しゃ=sya、じゃ=zya)
- 小書き単独 → x系(ぁ=xa、ゃ=xya)
- 外来音 combo3 は「基本かな+小書き」の**連結**送出(ふぁ=huxa、てぃ=texi)
- ー → `-`、ヴ → `vu`

### 補助テーブル

- `YOUON_CONS` / `YOUON_VOWEL` … 拗音の実機表記生成(romaji.rs の youon_consonant 準拠)
- `HEPBURN_YOUON` … しゃ=sha 等の代替候補
- `SPECIAL_UNITS` … 外来音の短縮代替(ふぁ=fa、てぃ=thi 等。実機表記ではない)
- `SMALL_KANA` … 結合対象の小書きかな集合(ぁぃぅぇぉゃゅょゎ)。**っ は含まない**

### LESSONS

10レッスン。各 `{ id, title, desc, items[] }`。
段階式: 中段単打 → 上段 → 下段 → センターシフト → 濁音 → 半濁音 → 拗音 → 外来音 →
総合単語 → 文章(、。を含む)。

**制約**: 各レッスンの語はそこまでに導入されたかなのみで構成する(レッスン追加時は
`test/run-tests.js` の全レッスン完走テストが守ってくれるのは「変換可能か」のみで、
「未習かなを含まないか」は人力レビューが必要)。

## 変更時の注意

- かなを追加する場合: `ROMAJI`(候補の先頭=実機表記)と `KANA_KEYS` の両方に追加する。
  emulator.js のテーブルは自動追従する。
- `KANA_KEYS` の2キー定義でシフトキーを先頭にしないと、emulator が combo2 と誤解釈する。
- `、` `。` は yaml ではかなでなく keys(Comma+Enter)だが、本アプリでは
  かな扱い(`ROMAJI['、']=[',']`)にして Enter をアプリ側で無視する設計。
