# 06. お題ファイル仕様(js/lessonio.js)

最終更新: 2026-06-11

## 取り込み経路

メニューの「お題ファイルの追加」セクション。

- `<input type="file">`(複数選択可)とドラッグ&ドロップの両対応。
- ドロップは `.txt` / `.json` 拡張子のみ受け付ける。
- 読み込み結果は `naginata-trainer:imported` に追記保存され、次回以降も表示される。
- 各カードの × ボタンで削除(そのお題のベスト記録も同時に削除)。

`file://` で開いた場合でも File API は使えるため、ローカルサーバは不要。
(fetch による `lessons/` フォルダ自動読み込みは file:// で CORS 制限があるため不採用。)

## ファイル形式

### .txt

```
# レッスンタイトル        ← 最初の # 行がタイトル(以降の # 行はコメント)
ねこ                      ← 1行1問
いぬ

うさぎ                    ← 空行は無視
```

### .json

単一オブジェクトまたは配列(複数レッスン一括):

```json
[
  { "title": "たべもの", "desc": "説明(省略可)", "items": ["おにぎり", "らーめん"] }
]
```

`items` が配列でない要素はスキップ。不正JSONは例外 → UIにエラー表示。

## バリデーション(normalize)

- 各行を trim し、`tokenize()` の結果が空(漢字・英数のみ等)の行は**除外**。
- 有効行が0件のレッスンは取り込まない(ファイル単位でエラー表示)。
- BOM付きUTF-8を許容(先頭BOMを除去)。
- ID は `imp-<時刻36進>-<乱数>` で生成(重複しない前提の簡易方式)。

## レッスンオブジェクト(localStorage 内)

```json
{
  "id": "imp-xxxx-yyyy",
  "title": "ことわざ",
  "desc": "ファイル名 から追加(N問)",
  "items": ["さるもきからおちる", "..."],
  "imported": true
}
```

組み込み `LESSONS` と同じ形で `startLesson()` にそのまま渡せる。

## サンプル

`samples/ことわざ.txt`(txt形式)、`samples/しりとり単語.json`(2レッスン入りJSON)。

## 制限・注意

- 文字コードは UTF-8 のみ(`File.text()` の仕様)。Shift-JIS のファイルは文字化けして
  全行除外になる(エラー表示で気づける)。
- localStorage 容量(通常5MB)を超える大量取り込みは想定外。
- タイトル重複は許容(IDで区別)。
