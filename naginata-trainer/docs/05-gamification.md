# 05. ゲーミフィケーション・効果音・演出仕様

最終更新: 2026-06-11

## スコア

| イベント | 加点 |
|----------|------|
| 正打鍵(ローマ字モード) | `round(10 × コンボ倍率)` / 打鍵 |
| 正入力(エミュモード) | `round(10 × コンボ倍率) × かな数`(チャンク単位) |
| お題クリア | +50 |
| お題ノーミスクリア(PERFECT) | +100(+50の代わり) |

コンボ倍率 = `1 + min(floor(combo/10), 4) × 0.25`(10コンボごとに+25%、最大×2)。
ミスでコンボは0に戻る。モード間でスコアの出方は厳密には揃わない(割り切り、01章)。

## ランク(レッスン終了時)

実効速度 `eff = かな/分 × (正確率/100)²` で判定:

| ランク | eff | スター |
|--------|-----|--------|
| S | ≥100 | ★★★ |
| A | ≥70 | ★★★ |
| B | ≥45 | ★★ |
| C | ≥25 | ★ |
| D | <25 | なし |

正確率を2乗で効かせるのは「速いが雑」を抑えるため。閾値は `rankOf()`(app.js)に集約。

## XP・レベル

- 獲得XP = `round(スコア/10) + ランクボーナス(S:100 / A:60 / B:30 / C:10 / D:0)`
- レベルLからL+1に必要なXP = `L × 100`(Lv1→2: 100、Lv2→3: 200…)。
  `levelInfo(xp)` が現在レベル・進捗・必要量を返す。
- カスタム練習(その場入力)はベスト記録を保存しないが、XPは入る。

## 自己ベスト

レッスンごとに `{kpm, acc, score, rank, stars}` を保存。**score の高い方を採用**。
レッスンカードに ★ とベスト値を表示する。

## 効果音(js/sound.js)

Web Audio API でその場合成(外部ファイルなし)。`AudioContext` は初回再生時に生成、
suspended なら resume(ブラウザの自動再生制限対策)。ミュートは localStorage 永続。

| API | 内容 |
|-----|------|
| `hit(combo)` | 打鍵音。C5メジャースケールを combo/5 段ごとに上がる(基音+オクターブ上の2層) |
| `miss()` | のこぎり波の下降ビープ + 60Hz の「ドン」 |
| `word()` | お題クリアの3音アルペジオ |
| `perfect()` | ノーミスクリアの4音(高域) |
| `combo()` | 25コンボごとの矩形波スパークル |
| `finish(rank)` | ランク別ファンファーレ(S=5音 … D=下降2音) |
| `best()` / `levelup()` | チャイム(結果表示の700ms後、ALL PERFECT時は1400ms後) |
| `allPerfect()` | 6音上昇 + 高音サスティン |

## 画面演出(js/fx.js + CSS)

- `Fx.burst(x, y, opts)` … 1点から放射状の火花(重力付き、減衰αとサイズ)。
- `Fx.confetti(opts)` … 画面上部から回転する矩形紙吹雪。
- 実装は全画面固定 `#fx-canvas` + requestAnimationFrame。パーティクルが尽きたら
  ループ停止・キャンバスクリア(アイドル時のCPU消費ゼロ)。

| トリガ | 演出 |
|--------|------|
| ミス | お題テキストのシェイク(CSS animation)+ミス音 |
| 25コンボごと | 「N COMBO!」ポップアップ + 暖色バースト + 効果音 |
| お題クリア | 「+50」ポップアップ + バースト |
| お題ノーミス | 「PERFECT! +100」金色ポップアップ + 金色大バースト + 専用音 |
| レッスン全体ノーミス | 結果画面で「✨ ALL PERFECT! ✨」+ 紙吹雪200 + 特別ファンファーレ |
| Sランク(ミスあり) | 紙吹雪(通常量) |
| ランク表示 | 拡大バウンドイン(CSS rank-in)、S=金グロー |

ポップアップ(`.fx-pop`)は `#fx-layer`(お題テキスト上の相対層)に生成し、
900msで自動削除。紙吹雪・火花はビューポート座標(`#fx-canvas`)。

## 練習中のUI状態

統計バー: 時間 / かな/分 / 正確率 / ミス / コンボ(25以上で赤の脈動)/ スコア。
250ms間隔の setInterval + 入力イベントごとに更新。計測は最初の打鍵から。
